Item order below **Next** is a proposal until the user reviews it (one decision per turn, HANDOFF "How to work").

CPU / memory work: `fw/OPTIMIZE.md` (ranked items, one a session; sizes: `python -I fw/tools/elf_sizes.py fw/build/dinghy.elf`).
Marks: `[x]` done (commit) · `[~]` in progress (uncommitted) · `[ ]` to do · `[!]` blocked (reason given)
Every item names its **check**: a section of `node fw/tests/tracker_emu.mjs` (build first:
`python web/dinghy-emu/build.py --app fw/firmware/src/tracker.c --name TRACKER --ver 0.1`), a listen, or a device step.
The spec for each item is the prototype (`ux-proto/`) and the `docs/ux/*.md` file named.
