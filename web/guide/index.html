Ketch: screens and controls

Ketch is a tracker firmware for the M-VAVE FM-1. Every picture below is the firmware itself, playing the demo song, in the emulator. Try it in the browser · Home

1 · The keybed is a gamepad

The tracker takes its eight controls from the keybed: a d-pad on the four lowest keys, laid out as an inverted T, and SHIFT, PLAY, OPTION and EDIT on the four highest white keys. Press REC on the panel to play notes on the middle keys instead.

In the emulator: A S W D = ◀ ▼ ▲ ▶ · J SHIFT · K PLAY · L OPTION · ; EDIT · Space panel PLAY · Tab REC · 1–0 the panel buttons.

2 · Screens and the map

SHIFT + ◀ ▶ moves along the main row: song, chain, phrase, instrument. SHIFT + ▲ ▼ moves up or down from where you are: above song, chain and phrase is the project page (G), below them the effects (F), then the mixer (X). Above the instrument is the event view (Q), below it the envelope (E), LFO (L) and voice (V) pages. The map in the corner of each screen shows where you are.

3 · Editing

d-padMove the cursor.
EDITOn an empty cell: put the last value used in that column. On a filled cell: copy it (the next EDIT on an empty cell pastes it).
EDIT + ◀ ▶Value −1 / +1.
EDIT + ▼ ▲Value −big / +big (a note: an octave; hex: 16; transpose: 12).
EDIT heldOn a list: a popup with every choice. On a note: a two-octave keyboard.
EDIT EDITSong or chain: a new empty chain or phrase (the next free number).
OPTION + EDITBack to the default (empty; on an empty note: a note off), or delete the selection.
SHIFT + OPTIONStart a selection; the d-pad extends it, OPTION copies it. On a row number: whole rows.
SHIFT + EDITPaste. On a selection in one column: interpolate. On chain or phrase numbers: clone them.
OPTION + ◀ ▶Chain, phrase: previous / next channel. Instrument pages: instrument −1 / +1.
OPTION + ▲ ▼Chain: the song row. Phrase: the chain row. Instrument pages: instrument +4 / −4.

4 · Playing

PLAYPlay what the screen shows: the song or the chain from the cursor row, or loop the phrase. PLAY again stops.
SHIFT + PLAYAll channels from the current song row, from any screen.
OPTION, then SHIFTMute / unmute the cursor's channel.
OPTION + PLAYSolo / unsolo it.
EDIT + PLAYHear the instrument (instrument pages) or the line (event view) while held.
REC (panel)1st: the middle keys play notes (stopped, on the phrase screen, they write at the cursor). 2nd: armed; PLAY then counts in and records where the playhead is. REC again: stop writing.
HOME (panel)Follow: while playing, the cursor follows the playhead.

5 · Projects (G page)

EDITLoad the slot.
EDIT EDITOn an empty slot: a new project there.
SHIFT + OPTION, then OPTIONCopy the slot.
SHIFT + EDITPaste into the slot.
OPTION + EDITDelete the slot.
SAVE (panel)Save the project (lit = unsaved).
GLO (panel)The project page; again: back.
EDIT + OCT− / OCT+ (panel)Undo / redo.
